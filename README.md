# 🔫 Revy

**Revy** is a fast, lightweight, and modern CLI application written in C# (.NET 8), heavily inspired by the `ani-cli` project. It allows you to browse, watch, and download anime directly from your favorite terminal — completely ad-free, without heavy browsers, and without unnecessary clicks.

## 🚀 Getting Started

Clone the repository and run the project using the .NET CLI:

```bash
git clone https://github.com/pazurkota/revy.git
cd revy
dotnet run --project Revy.Cli
```
